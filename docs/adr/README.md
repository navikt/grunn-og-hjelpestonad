# Arkitekturbeslutninger

Denne katalogen inneholder Architecture Decision Records (ADR-er) for tekniske
valg som påvirker arkitektur, sikkerhet, plattform eller vedlikehold over tid.
Hver ADR beskriver én beslutning og skal ikke endres etter at den er erstattet,
utover å oppdatere status og lenke til den nye ADR-en.

## Statuser

- **Foreslått:** Beslutningen er til vurdering.
- **Godkjent:** Beslutningen gjelder for løsningen.
- **Forkastet:** Forslaget ble ikke valgt.
- **Erstattet:** En nyere ADR har overtatt.
